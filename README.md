## 📌 Descripción del Proyecto
Transformación de los registros tabulares estáticos en Excel de la bitácora de seguimiento a un sitio web interactivo y accesible desarrollado estrictamente en **HTML puro (sin CSS externo)**, cumpliendo con los estándares semánticos de HTML5.

## 📂 Estructura de las Tres Vistas
1. **`index.html` (Información):** Datos oficiales del aprendiz, programa formativo y ficha.
2. **`reglas.html` (Reglas Técnicas):** Normativa de operación y guía detallada de llenado estructurada en tablas semánticas.
3. **`trazabilidad.html` (Tabla de Trazabilidad):** Registro histórico detallado con los 4 eventos ejecutados en el proceso.

## 🛠️ Tecnologías Usadas
- Git Bash / Git CLI para control de versiones mediante flujo de trabajo por ramas (`feature/...`).
- HTML5 semántico puro (`<header>`, `<nav>`, `<main>`, `<section>`, `<table>`, `<footer>`).
